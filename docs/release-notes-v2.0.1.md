# V2.0.1 · 修掉两个 P1

补丁版本，只修代码审核里确认的两个 P1，不改手感数值、不改关卡规则。

**在线试玩**：<https://gubao-tian.github.io/rail-runner/>

## 修复

**1. 换道途中被护盾挡下，角色会永久卡在两轨之间**

受击会打断 `switchLane`，但位置停在插值中途、`lane` 仍是旧轨，导致渲染与判定都偏在一侧，下一次换道还会从错误起点插值。

现在受击时先把位置结算到**最近的一条轨道**（`Player.snapToNearestLane()`），再进入受击硬直。

复现脚本实测：修复前偏移 **1.200 m**，修复后 **0.000 m**。

**2. 埋点每次按键同步写约 30 KB 到 localStorage**

`Telemetry.log()` 原先是"每记一条就整块序列化 + 同步写盘"，而 `input_cmd` 对每条指令都记一次。400 条记录实测 29.8 KB，按键 3~5 次/秒时相当于每秒上百 KB 的同步 I/O，低端移动端有掉帧风险。

改动三处：

- 写盘合并成 **1 秒节流**（`scheduleFlush`），不再每次按键都落盘；
- 死亡结算、暂停、页面隐藏/卸载时 **立即落盘**（`flushNow`），不丢关键记录；
- `input_cmd` 只记录**被接受**的指令，被丢弃的改为按局计数，随 `run_end` 上报 `rejected_inputs`。

## 尚未处理（仍是已知问题）

- 暂停时粒子仍在动
- 帧率统计把恢复首帧的 `dt=0` 当成 10000fps 计入均值
- 5 个从未被引用的配置项（`dropWeight` / `poolBlocks` / `restartAuto` / `magnetPull` / `fogStart`）
- 站姿骨骼高度写死在 `render.js`，与 `config.player.height` 脱钩
- 死亡没有姿态表现（`view.dead` 传了但没用）
- 集成路径（暂停/恢复/结算/重开）缺可回归的自动化断言
