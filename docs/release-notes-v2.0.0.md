# V2.0.0 · 首个可玩版本

三轨无限跑酷，纯 Web 实现：零依赖、零素材、离线可玩，按 PRD V2.0 的 P0 需求完成。

**在线试玩**：<https://gubao-tian.github.io/rail-runner/>

## 这一版有什么

- **三轨五指令**：跳 / 滑铲 / 左 / 右 / 道具；空中禁二段跳、滑铲期禁跳、换道 120ms 期间锁全部输入
- **确定性关卡**：同一 seed 必得同一关卡；无三轨全封、无连续双轨；前 3 块地是纯金币 → 教跳 → 教滑的新手保护区（判定放宽 1.5 倍）
- **难度曲线**：速度按 `v(d) = 12 + 14(1 − e^(−d/600))` 逼近 26 m/s，地块权重同步偏移
- **可解释死亡**：慢动作 + 撞击点高亮 + 六类归因文案（起跳过早/过晚、没跳、滑铲过早、没滑铲、换道时机不对）
- **道具**：护盾、磁铁、双倍，拾取入包、主动使用、倒计时结束自动关闭
- **存档**：死亡瞬间落盘，tmp→主键→回读校验→备份四级写入，损坏自动降级为默认存档
- **动作**：下蹲带 90ms / 220ms 缓动，只降重心不前倾；站姿、跳跃、滑铲三套姿态连续插值
- **音频**：全部 WebAudio 实时合成，仓库里没有任何音频或图片文件
- **皮肤 / 设置 / 本地埋点**：按最高里程解锁皮肤，画质档位、震动、音效音乐独立开关

## 已知问题（下一版修）

1. **换道途中被护盾挡下会卡在两轨之间**（`js/fsm.js` 的 `hit()` 未结算进行中的换道，实测偏移 1.2m）
2. **埋点每次按键同步写约 30KB 到 localStorage**，低端移动端有掉帧风险

完整代码审核结论见会话记录；修复后会以 V2.0.1 发布。
