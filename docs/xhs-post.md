## 正文

```
先说结论：做完了，能玩了 🎮

玩：gubao-tian.github.io/rail-runner/
（小红书正文放不了链接，地址我放评论区第一条）

——今天按顺序做了四件事

1️⃣ 先把"手感"关进一个文件
起跳初速、滞空 0.69 秒、换道 120 毫秒、判定宽容度……全部塞进同一个 config。
改数值不改代码，后面调什么都快。

2️⃣ 让死亡变得"可解释"
撞了不弹 Game Over，而是告诉你"起跳过早"还是"滑铲过晚"，
还会把撞到的那块障碍高亮 1.5 秒。
跑酷最劝退的从来不是难，是死得不明不白。

3️⃣ 自己审自己，审出两个真 bug
· 换道换到一半被护盾挡下 → 角色永远卡在两条轨道中间，偏 1.2 米
· 埋点每按一次键就同步写 30KB 到本地存储 → 手机上会掉帧
都修了，为此单独发了补丁版本。

4️⃣ 补一套独立验证
165 项离线断言
6 个种子 × 240 公里"完美玩家"模拟，0 次死亡（证明关卡无解率为 0）
浏览器自检 14/14
又用 Python 独立写了个校验器，10 万块地交叉验证

——一天发了 3 个版本
v2.0.0 能玩 → v2.0.1 修 bug → v2.1.0 补校验

说点真话。

早上打开那份 664 行的 PRD 时，第一反应不是兴奋，是心虚。
它把"公平"写成了硬约束：不许三轨全封、不许连续双轨、
前 3 块地必须留两条活路。
这些东西在游戏里看不见，但少一条，玩家就会在某一次死亡里觉得"这游戏在耍我"。

真正让我坐直的是那句"死得明白"。
做过不少小东西，第一次见到有人把"玩家为什么会觉得自己冤"
当成需求，写进文档里。

中间有一段很难受：自己审自己的代码，审出两个 bug。
一个是最得意的护盾——换道到一半被它挡下，
角色会永远卡在两条轨道中间，偏 1.2 米。
那一刻的感觉不是"我错了"，是"它在我看不见的地方骗人"。

后来跑那个 240 公里的模拟，六个种子，一次没死。
屏幕上一行绿字，我在椅子上坐了一会儿。
那不代表游戏好玩，但它代表每一块地都真的过得去——
这是今天唯一敢说"确定"的事。

还有一个很小的瞬间。
动画里的蹲下，一开始是整个人往前扑出去，看着挺帅，但不像"蹲"。
改成只降重心、身体保持直立，前后不过二十几行。
盯着那个小人从"扑"变成"蹲"的时候，
突然明白"柔和"不是参数，是别人看一眼就知道对不对的东西。

现在它上线了，两个地址都能玩。
剩下 6 个小毛病没修完，也不打算今天修完。

做东西最爽的从来不是"做完了"，
是"它开始像一个东西了"。
```
